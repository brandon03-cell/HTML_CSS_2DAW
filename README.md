# HTML y CSS - 2º DAW

Repositorio con los ejercicios y prácticas de HTML y CSS del curso.

## Contenido

| Carpeta | Descripción |
|---|---|
| `lecciones/` | Ejemplos de las lecciones |
| `EjerciciosCSS1/` | Ejercicios 1 a 6 de CSS |
| `comentarios/` | Los mismos ejercicios, con los estilos comentados |
| `Practicar/` | Prácticas sueltas (currículum) |
| `PracticaIV/` | Práctica IV (ejercicios 1 a 3) |
| `DepilacionLaser/` | Proyecto de página web de una clínica de depilación láser |
| `Imagenes/` | Imágenes usadas en los ejercicios |

## Cómo verlo

No necesita instalación. Abre cualquier archivo `.html` en el navegador.
